Способы вывода

Выберите минимальный уровень сообщений и единственное место вывода для стандартного журнала AIBuds.

API Reference​

Framework​

AIBudsLog.xcframework

Declaration​

  • Swift
  • Objective-C

См. logConfiguration, LogLevel и LogDestination.

Уровни журналирования​

level задаёт минимальную записываемую важность. Сообщения более низких уровней отбрасываются.

УровеньНазначение
.verboseПодробная трассировка выполнения.
.debugДиагностика во время разработки.
.infoОбычный ход работы и служебная информация.
.warnСостояние, которое может потребовать внимания.
.errorОшибка, после которой приложение может продолжить работу.
.fatalКритическая ошибка, способная завершить приложение.
.muteПолностью отключить вывод журналов.

Места вывода​

МестоВыводЭкспорт
.consoleКонсоль отладчика XcodeНет
.osloggerЕдиная система журналирования Apple через os_logНет
.fileФайлы в настроенном каталоге относительно DocumentsДа
.xlfacilityПлагин хранения AIBudsXLFacilityДа, если плагин установлен

Примеры использования​

  • Swift
  • Objective-C

Примечания​

  • Место вывода задаётся для всего процесса и заменяет предыдущее; это не набор одновременно активных выходов.
  • logsDirectory принимает путь относительно Documents. SDK удаляет начальный символ косой черты.
  • Значения maxFileSize и logFileMaxAge, меньшие либо равные нулю, игнорируются.
  • Публичный SDK не предоставляет настройку удалённого сервера журналов и переключатели категорий.
