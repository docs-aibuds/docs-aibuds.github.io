Глоссарий SDK

Краткие определения терминов из документации AIBuds SDK. Применение возможностей описано в руководствах, а взаимосвязь компонентов SDK — в разделе Архитектура.

Bluetooth и подключение​

BLEBluetooth Low Energy

Радиоканал для поиска устройств, установления управляющего соединения SDK и обмена командами. Реализацию поддерживаемого протокола устройства предоставляет модуль ABMate.

RSSIReceived Signal Strength Indicator

Знаковое значение в dBm, показывающее уровень принятого BLE-объявления. Это ориентир близости, а не измерение расстояния или гарантия качества соединения.

Advertisement Data

Метаданные из BLE-трансляции peripheral. Дескриптор найденного устройства предоставляет снимок объявления вместе с peripheral и RSSI.

Core Bluetooth ObjectsCBCentralManager / CBPeripheral

Central manager Apple управляет поиском и подключениями, а peripheral представляет одно удалённое BLE-устройство. SDK оборачивает эти объекты своими абстракциями устройств.

Classic Bluetooth

Отдельный канал Bluetooth, обычно используемый аудиопрофилями. Его состояние не зависит от управляющего BLE-соединения.

SCOSynchronous Connection-Oriented

Голосовой канал Classic Bluetooth для двустороннего звука звонка или речи на поддерживаемых устройствах.

Beacon Data

Необязательные данные производителя, передаваемые без активного соединения. Используйте их только при наличии beacon payload у найденного устройства.

Понятия устройств​

Discovered DeviceFoundDeviceConvertible

Результат поиска в виде FoundDeviceConvertible. Перед сохранением или подключением преобразуйте его средствами SDK.

Storable DeviceDeviceConvertible

Постоянный дескриптор DeviceConvertible для идентификации, состояния соединения, сохранения, команд, delegate и проверки возможностей.

StoredDevicesMgr

Общий для процесса менеджер сохранённых устройств приложения. Сохранённые устройства могут участвовать в поддерживаемом автоматическом переподключении.

Device Ready

Состояние жизненного цикла после подключения и handshake SDK. Перед командами функций дождитесь deviceDidReady или проверьте isConnectedAndReady.

Capability Protocol

Небольшой необязательный протокол *API, реализуемый только при поддержке функции устройством. Выполняйте cast к нужному протоколу, не предполагая одинаковые возможности всех моделей.

Device State

Рабочее состояние, сообщаемое устройством. Оно отличается от peripheral state в Core Bluetooth, которое описывает только BLE-канал.

Work Mode / Work State

Work mode — настроенный режим устройства, work state — текущая сообщаемая активность. Оба значения являются снимками и могут меняться через события delegate.

Wear Detection

Возможность устройства, сообщающая о поддержке и включении определения ношения, а также о текущем состоянии ношения.

TWSTrue Wireless Stereo

Описывает связанную пару левого и правого беспроводных устройств. SDK отдельно сообщает признак TWS и подключение второго устройства пары.

Auto Reconnect

Настройка каждого устройства, определяющая переподключение после повторного обнаружения при запуске приложения или перезапуске Bluetooth. Начальное значение задаёт конфигурация SDK.

Аудио и голос​

VADVoice Activity Detection

Обработка сигнала, отличающая речь от тишины и фонового шума. AI-аудиоинтеграции могут применять её для разделения или фильтрации входящего звука.

Standard Recording

Запись на устройстве, запускаемая и останавливаемая через его возможность аудиозаписи. Результат команды сам по себе не возвращает локальный аудиофайл.

AI Audio Recording

Совместный процесс устройства и AI-сервиса: устройство передаёт аудио, а выбранный сервис формирует события сеанса, обновления расшифровки и итоговый отчёт.

Recording Scene

Контекст записи устройства, передаваемый при запуске AI-аудиозаписи. Публичные значения различают запись на месте и запись звонка.

PCMPulse-Code Modulation

Несжатые цифровые аудиосэмплы. PCM удобен для обработки, но требует больше пропускной способности и места, чем сжатый звук.

Opus

Сжатый аудиокодек с низкой задержкой для поддерживаемых голосовых и потоковых каналов.

On-Device Voice Assistant

Обработка активации и команд через OnDeviceVoiceAssistantAPI в поддерживаемой прошивке носимого устройства. Для авторизации могут потребоваться зарегистрированный bridge plugin и среда интеграции.

AI и обработка речи​

ASRAutomatic Speech Recognition

Преобразует речь в текст. SDK предоставляет потоковое распознавание на основе сеанса и service API для поддерживаемых источников.

Streaming ASR

Распознавание с промежуточными обновлениями текста по мере поступления аудио, без ожидания единственного итогового результата.

TTSText to Speech

Преобразует текст в аудиофайл. TTSResultModel предоставляет относительный audioFile, его audioFormat и разрешённый audioFilePath.

AI Summary

Создаёт краткий результат из исходного текста или расшифровки. Поддерживаемые сервисы могут передавать результат частями.

Text Translation

Переводит переданный текст между настроенными языками. Это отдельная функция, не связанная с непрерывными речевыми сеансами.

Simultaneous Interpretation

Сеанс в реальном времени, объединяющий входящий звук, потоковое распознавание, перевод и поддерживаемый аудиовывод на целевом языке.

AI Chat

Диалоговый сеанс на базе AI-сервиса, передающий события расшифровки, чата, намерений, голоса, жизненного цикла, ошибок и итогового отчёта.

AI Intent

Структурированные данные действия, извлечённые из диалога. Они отделены от свободного текста и имеют смысл только при выдаче выбранным сервисом.

AI Service ProviderAIServiceVendor / AIBudsAIServiceVendor

Зарегистрированный сервис, выбранный для AI-вызовов. В имени публичного enum сохраняется Vendor, а в документации используется «поставщик сервиса». Установка модуля, регистрация, инициализация и выбор — отдельные этапы.

StarBurst AI.starBurst / AIBudsAIServiceVendorStarBurst

AI-сервис ByteDance. Перед выбором для AI-вызовов приложение использует модуль AIBudsStarBurst и регистрирует сервис через StarBurstSDK.

MltCloud AI.mltcloud / AIBudsAIServiceVendorMltcloud

AI-сервис Meilc. Перед выбором для AI-вызовов приложение использует модуль AIBudsMagicHelper и регистрирует сервис через MagicHelperSDK.

Authorized Services

Сообщаемая устройством битовая маска поддерживаемых сервисов, завершивших authorization handshake. Это не общий список установленных AI-модулей.

AI Dashboard

Необязательный локальный интерфейс диагностики AI-сеансов, событий, отчётов и ошибок при разработке или поиске проблем.

Настройка звучания​

EQEqualizer

Настройка усиления по частотным полосам. Используйте сообщаемые устройством параметры, поскольку ограничения custom EQ пока не образуют полного публичного контракта.

Preset EQ

Настройка эквалайзера от устройства, например заводской профиль звучания. Набор preset зависит от модели и прошивки.

ANCActive Noise Cancellation

Обработка на устройстве для снижения окружающего шума. Публичный mode также различает normal и transparency.

Transparency Mode

Режим ANC, пропускающий окружающий звук через носимое устройство вместо его подавления.

ANC Fade

Поддерживаемая настройка плавного изменения ANC. Слышимый эффект определяется устройством.

Volume Domains

Независимые уровни громкости системных подсказок, мультимедиа, звонков и доступного для чтения локального воспроизведения. Перед изменяемым элементом управления проверяйте возможности устройства.

VolumeSetCapability

Битовая маска операций настройки громкости, поддерживаемых текущим устройством.

Изображения, потоки и хранилище​

Remote Shutter

Запрос устройства к приложению на открытие камеры, съёмку или выход. Камерой управляет приложение, после чего сообщает результат устройству.

Capture Mode

В CaptureMode значение .camera сохраняет фото высокого разрешения на устройстве, а .ai отправляет JPEG 320×240 в приложение.

RTSPReal-Time Streaming Protocol

URL сеанса для воспроизведения прямого потока камеры поддерживаемого устройства после успешного подключения hotspot и запуска потока.

JPEG Live Streaming

Поток полных сжатых JPEG-изображений через callback. Каждый callback передаёт изображение, а не недекодированный raw video frame.

RTMPReal-Time Messaging Protocol

Необязательный канал публикации прямого потока на совместимый endpoint. Его жизненный цикл отделён от сеанса устройства и локального player.

Media File Import

Процесс hotspot от устройства к приложению через DeviceMediaFileImportAPI. Он получает метаданные, загружает выбранные файлы и при необходимости выполняет локальную стабилизацию видео.

MediaCountInfoModel

Текущее количество элементов в поддерживаемых категориях мультимедиа, сообщённое устройством после успешного обновления.

StorageInfoModel

Текущие объёмы занятого и свободного хранилища, сообщённые устройством. Публичная модель выражает их в мегабайтах.

Обновления OTA​

OTAOver-the-Air Update

Обновляет основную прошивку устройства из совместимого локального пакета, предоставленного приложением.

Camera OTA

Отдельный процесс прошивки поддерживаемого модуля камеры: подключение hotspot, локальная HTTP-доставка, передача, flashing и завершение.

OTA Battery Limit

Минимальный процент заряда для запуска обновления основной прошивки. Значение 0 означает отсутствие порога заряда.

Архитектура SDK​

SDKDelegate / DeviceDelegate

SDKDelegate получает общие события поиска и устройств, а DeviceDelegate — события конкретного устройства.

All-in-One

Общая установка и удобный initializer полного поддерживаемого набора SDK. Модульная интеграция даёт приложению более точный контроль зависимостей и plugin.

Bridge Plugin

Необязательный adapter, подключающий авторизацию или сервис конкретного поставщика к core SDK через публичную границу plugin.

ConnectParams

Значения отдельного подключения: идентификатор пользователя, данные pairing, предпочтение Classic Bluetooth и необязательные параметры AI-авторизации.

LogService

Активный во всём процессе backend LogService. Один настроенный приёмник обрабатывает вывод; поддерживаемые постоянные приёмники также позволяют экспорт и очистку.

SDKConfiguration

Начальные значения подтверждённого поведения SDK: уровень журнала, тайм-аут поиска, автоматическое переподключение и фильтрация известных устройств.
