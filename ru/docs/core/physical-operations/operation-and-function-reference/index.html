Операции и функции

DeviceOperation обозначает действие, которое сообщает устройство. DeviceFunction обозначает назначенное этому действию поведение.

Символы ниже описывают логические элементы управления. Иллюстрации намеренно абстрактны и не задают форму устройства, размещение элементов или жесты конкретного продукта.

Использование назначений устройства​

physicalOperationsMapping остаётся достоверным источником для подключённого устройства. Показывайте только операции из этого сопоставления и считайте назначение поддерживаемым лишь после подтверждения устройством.
