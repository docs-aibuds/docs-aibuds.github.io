Обновление прошивки камеры

Camera OTA обновляет прошивку модуля камеры поддерживаемого устройства. Этот процесс выполняется отдельно от обновления основной прошивки устройства.

Приложение предоставляет совместимый локальный пакет прошивки камеры. SDK координирует весь процесс: настраивает точку доступа устройства, переводит камеру в режим OTA, запускает локальный HTTP-сервер, передаёт устройству URL прошивки, загружает пакет и прошивает модуль камеры. Показывайте текущий этап по соответствующим обратным вызовам, а окончательный результат определяйте только по финальному обработчику завершения.

Завершение

Результат обновления берите из финального обратного вызова, а не из прогресса передачи.

↳Окончательный результат определяйте по финальному обратному вызову.

Предварительные требования​

  • Устройство подключено и поддерживает DeviceCameraOtaAPI.
  • Локальный файл прошивки доступен для чтения и соответствует модулю камеры.
  • Приложение может подключиться к точке доступа устройства, работать в локальной сети и поддерживать доступность локального HTTP-сервера.
  • Не запускайте одновременно импорт медиафайлов, Camera OTA и другие процессы через точку доступа.

Справочник API​

Фреймворк​

AIBuds.xcframework

Импорт​

  • Swift
  • Objective-C

Протокол​

Протокол DeviceCameraOtaAPI наследует DeviceAPI и предоставляет один метод экземпляра, выполняющий весь процесс Camera OTA.

Метод экземпляра​

  • Swift
  • Objective-C

См. startCameraOta в справочнике API.

Возвращаемое значение​

Метод не возвращает значение напрямую. Запуск, переходы между этапами, прогресс и окончательный результат передаются через обработчики.

Этапы процесса​

Это этапы обратных вызовов процесса Camera OTA, а не значения CameraOtaProgressPhase.

ЭтапСвязанные обработчики
Настройка точки доступаconfigureHotspotStartingHandler, hotspotConfigureCompletionHandler
Переход в режим Camera OTAenterCameraOtaModeStartingHandler, enterCameraOtaModeCompletedHandler
Подключение к точке доступа устройстваwaitingForHotspotOpenHandler, connectDeviceHotspotStartingHandler, deviceHotspotConnectCompletionHandler
Запуск локального HTTP-сервераhttpServerStartingHandler, httpServerStartCompletionHandler
Передача URL прошивкиsendingFirmwareUrlHandler, firmwareUrlSendCompletionHandler
Запуск обновленияstartCompletionHandler
Передача прошивкиfileTransferStartedHandler, fileTransferCompletedHandler
Подготовка и прошивкаwaitingForFlashingHandler, flashingStartedHandler, flashingCompletedHandler
ЗавершениеcompletionHandler

Фазы прогресса​

CameraOtaProgressPhase содержит два открытых значения. Аргумент progress — целое число от 0 до 100 для указанной фазы.

SwiftObjective-CИсходное значениеЗначение
.transferringAIBudsCameraOtaProgressPhaseTransferring1Прогресс передачи файла прошивки.
.flashingAIBudsCameraOtaProgressPhaseFlashing2Прогресс прошивки камеры.

Примеры использования​

В примерах сохранены все обратные вызовы из демо SDK. В рабочем приложении обновляйте интерфейс в главной очереди.

  • Swift
  • Objective-C

Обработка ошибок​

Ошибки Camera OTA используют AIBudsSDK.CameraOtaErrorDomain и SdkCameraOtaErrorCode. Открытое перечисление охватывает проверку локального файла, сбои сети и точки доступа, жизненного цикла задачи, перехода в режим OTA и передачи URL прошивки.

КодыТипичная причина
unknown, networkRequestFailed, networkTimeoutSDK не может точнее классифицировать ошибку либо произошёл сетевой сбой.
cameraOtaFileNotFound, invalidCameraOtaFile, cameraOtaTaskCreateFailedDueToFileNotFoundЛокальный файл не найден или пакет прошивки недействителен.
hotspotDisconnectedDuringTransfer, invalidHotspotConfigТочка доступа устройства работает нестабильно или настроена неверно.
stageTwoTimeout, interruptedByShutdownOrLowBatteryПрошивка зависла близко к завершению либо устройство прервало обновление.
cameraOtaTaskAlreadyRunningУже выполняется другая задача Camera OTA.
4003...4009Ошибка подключения, тайм-аут, сбой настройки точки доступа, перехода в OTA, HTTP-сервера или передачи URL.
5001...5010Устройство отклонило переход в OTA или URL из-за команды, хранилища, разрешений, канала или текущего состояния.

Показывайте этап, на котором произошла ошибка, а не общее сообщение об обновлении. После начала прошивки не выполняйте автоматический повтор, отключение, выключение или другой процесс через точку доступа. SDK пока не задаёт безопасные границы повтора: прежде чем предложить другой пакет, проверьте состояние восстановления и версию прошивки камеры.

Рекомендации​

  1. До вызова API проверьте наличие локального файла; подлинность пакета и совместимость с моделью камеры проверяет приложение.
  2. Не запускайте одновременно импорт медиафайлов, Camera OTA и другие процессы через точку доступа.
  3. До финального завершения сохраняйте приложение активным, а локальный HTTP-сервер — доступным.
  4. Обновляйте интерфейс в главной очереди: обратные вызовы могут поступать из другой очереди.
  5. startCompletionHandler сообщает только о запуске OTA, а не об окончательном результате обновления.
  6. Окончательный результат берите из completionHandler, а после повторного подключения проверяйте состояние прошивки камеры.

Примечания​

  • Camera OTA использует локальный файл; SDK не обращается к удалённому сервису обновлений и не загружает пакет.
  • phaseProgressHandler сообщает только о передаче и прошивке. Для остальных этапов предусмотрены отдельные обратные вызовы.
  • Значение 100 для передачи ещё не означает завершение Camera OTA: далее выполняется прошивка и приходит финальный результат.
  • Безопасное автоматическое повторение операции пока не определено открытым контрактом SDK.
