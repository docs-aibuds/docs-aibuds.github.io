Быстрый старт

В этом руководстве последовательно рассмотрены базовая настройка AIBuds SDK iOS и основные операции.

Шаг 1. Импортируйте SDK​

Импортируйте нужные модули в файлах, где используется SDK:

  • Swift
  • Objective-C

Шаг 2. Инициализируйте SDK​

Инициализируйте AIBuds SDK при запуске приложения — обычно в AppDelegate или SceneDelegate:

  • Swift
  • Objective-C

Шаг 3. Найдите устройства​

Запустите поиск доступных устройств AIBuds:

  • Swift
  • Objective-C

Шаг 4. Добавьте устройство​

Добавьте найденное устройство в раздел «Мои устройства», чтобы оно сохранялось между запусками приложения. Преобразуйте полученный при поиске FoundDeviceConvertible методом makeStorableDeviceFromDiscovered(_:), затем сохраните его через StoredDevicesMgr:

  • Swift
  • Objective-C

Шаг 5. Подключитесь к устройству​

Подключитесь к сохраненному устройству с помощью ConnectParams. Параметры авторизации AI позволяют SDK одновременно авторизовать выбранные AI-сервисы:

  • Swift
  • Objective-C

Шаг 6. Отправьте команды​

После подключения можно отправлять команды устройству:

  • Swift
  • Objective-C

Шаг 7. Обработайте события делегата​

Реализуйте протокол DeviceDelegate, чтобы получать события жизненного цикла подключения. Все методы объявлены как @objc optional, поэтому достаточно реализовать только нужные callback:

  • Swift
  • Objective-C

Шаг 8. Отключитесь от устройства​

Завершив работу с устройством, отключитесь от него:

  • Swift
  • Objective-C

Пример приложения​

Полный пример интеграции SDK в приложение приведен в проекте AIBudsSDK-Demo.
