Установка

Установите AIBuds SDK через CocoaPods. Если точный набор возможностей приложения еще не определен, начните с полной установки.

Требования​

  • iOS 13.0 или новее
  • Xcode 26.0 или новее
  • CocoaPods 1.16.0 или новее

Выберите способ установки​

Рекомендуется

Полная установка

Подключите AIBudsSDK/AllInOne, чтобы вместе установить компоненты для связи с устройствами, AI-сервисов, голосового помощника, мультимедиа, диагностики и других дополнительных возможностей.

Меньше зависимостей

Модульная установка

Выберите только используемые в продукте возможности. Необходимые уровни SDK и сторонние зависимости CocoaPods установит автоматически.

Установка с помощью AI

Интеграция с AI-ассистентом

Выберите способ установки и вставьте короткий промпт в AI-ассистенте, открытом в рабочей папке проекта.

Установить полный SDK через AIBudsSDK/AllInOne.

Прочитайте и выполните инструкции https://docs-aibuds.github.io/skills/integrate-aibuds-sdk. Интегрируйте AIBudsSDK/AllInOne в этот iOS-проект и проверьте интеграцию.

Шаг 5. Проверьте установку​

  • Соберите созданный .xcworkspace.
  • Убедитесь, что target импортирует установленные framework AIBuds.
  • После добавления обязательных Bluetooth key убедитесь, что AIBudsSDK.initialize возвращает true.
  • Перейдите к разделу Быстрый старт, чтобы инициализировать SDK и подключить устройство.

Если установка или инициализация завершилась ошибкой, сначала выполните проверки из раздела Частые проблемы и только затем изменяйте cache Pod или lockfile.
