संवाद अनुवाद

Active speaker के लिए छोटा simultaneous-interpretation session शुरू करके और दूसरे participant के लिए source तथा target languages बदलकर दो लोगों का बारी-बारी अनुवाद अनुभव बनाएँ।

यह ConversationTranslationDemoController में दिखाया गया product workflow है; इससे अलग ConversationTranslationAPI नहीं जुड़ती।

आवश्यक शर्तें​

  • Simultaneous Interpretation की सभी आवश्यक शर्तें पूरी करें।
  • Source और target के लिए अलग hyphenated language identifiers उपयोग करें।
  • Host app में active speaker, current session, start/stop state और दिखाई गई turn messages track करें।
  • दोनों speakers को एक साथ sessions शुरू करने से रोकें।

API Reference​

संवाद अनुवाद में startSimultaneousInterpretation, stopSimultaneousInterpretation और SimultaneousInterpretationConfig उपयोग होते हैं।

पूरे public declarations और callback contract के लिए Simultaneous Interpretation देखें।

उपयोग के उदाहरण​

Speaker की बारी शुरू करें​

Demo में “Me” को myLanguage → partnerLanguage और “Partner” को उलटी दिशा से map किया गया है। नीचे के helpers resolved direction लेते हैं, जिससे product state स्पष्ट रहती है।

  • Swift
  • Objective-C

Active बारी रोकें​

currentSession.isRecordingInternally के false होने पर service रोकने से पहले device-side AI recording रोकें, ताकि अंतिम audio सही क्रम में पहुँचे।

  • Swift
  • Objective-C

त्रुटि प्रबंधन​

Startup failure, interruption, recoverable exception, stream error, device-recording failure और final completion को अलग-अलग संभालें। Device recording शुरू होते समय stop request आए तो device start callback पूरा होने तक service stop टालें; Demo इस race को स्पष्ट रूप से track करता है।

ध्यान देने योग्य बातें​

  • Conversation में कई turns हो सकती हैं, लेकिन एक समय में केवल एक interpretation session active होना चाहिए।
  • Languages केवल तब बदलें जब कोई turn active न हो।
  • हर callback को सीधे जोड़ने के बजाय निश्चित segments को क्रम देने के लिए source और target sequence fields उपयोग करें।
  • External device recording उपयोग करते समय device audio शुरू करने से पहले retained interpretation session को app के PCM forwarding path से जोड़ें, ताकि पहला packet न खोए।
