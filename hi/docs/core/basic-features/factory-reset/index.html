फैक्ट्री रीसेट

फैक्ट्री रीसेट ऑपरेशन डिवाइस को उसकी मूल फैक्ट्री सेटिंग्स पर पुनर्स्थापित करता है, सभी उपयोगकर्ता डेटा और कस्टम कॉन्फ़िगरेशन मिटा देता है। यह ऑपरेशन डिवाइस को पुनर्विक्रय के लिए तैयार करने या लगातार समस्याओं का निवारण करने में उपयोगी है।

पूर्वापेक्षाएं​

फैक्ट्री रीसेट करने से पहले, सुनिश्चित करें:

  • डिवाइस कनेक्टेड और स्थिर स्थिति में है
  • सभी महत्वपूर्ण डेटा का बैकअप लिया गया है
  • उपयोगकर्ता समझता है कि सभी व्यक्तिगत डेटा मिटा दिया जाएगा

API संदर्भ​

फ्रेमवर्क​

AIBuds.xcframework

आयात​

SDK का उपयोग करने वाली फ़ाइलों में, मुख्य हेडर आयात करें:

  • Swift
  • Objective-C

प्रोटोकॉल​

factoryReset विधि निम्नलिखित प्रोटोकॉल में परिभाषित है। प्रोटोकॉल बेस डिवाइस API प्रोटोकॉल से इनहेरिट करता है।

  • Swift
  • Objective-C

इंस्टेंस विधि​

डिवाइस को उसकी मूल फैक्ट्री सेटिंग्स पर पुनर्स्थापित करता है, सभी उपयोगकर्ता डेटा और कस्टम कॉन्फ़िगरेशन मिटा देता है।

iOS 13.0+

  • Swift
  • Objective-C

पैरामीटर​

पैरामीटरप्रकारविवरण

कॉलबैक पैरामीटर:

नामप्रकारविवरण

errorNSError?यदि ऑपरेशन विफल हुआ तो त्रुटि जानकारी शामिल है, अन्यथा nil।

रिटर्न मान​

यह विधि सीधे कोई मान लौटाती नहीं है। परिणाम पूर्णता कॉलबैक के माध्यम से प्रदान किया जाता है।

सर्वोत्तम प्रथाएं​

  1. उपयोगकर्ता की पुष्टि करें: फैक्ट्री रीसेट शुरू करने से पहले हमेशा पुष्टि संवाद प्रदर्शित करें, क्योंकि यह ऑपरेशन अपरिवर्तनीय है।

  2. बैकग्राउंड निष्पादन संभालें: UI अपडेट करते समय पूर्णता हैंडलर को DispatchQueue.main.async ब्लॉक में रैप करें।

  3. वीक सेल्फ रेफरेंस: रिटेन साइकिल को रोकने के लिए पूर्णता हैंडलर में [weak self] का उपयोग करें।

  4. प्रोटोकॉल समर्थन जाँचें: विधि को कॉल करने से पहले पुष्टि करें कि डिवाइस DeviceCommonAPI प्रोटोकॉल का समर्थन करता है।

  5. संदर्भ साफ़ करें: सफल फैक्ट्री रीसेट के बाद, आपको डिवाइस को पुनः जोड़ना पड़ सकता है।

नोट्स​

  • फैक्ट्री रीसेट पूरा होने में कई सेकंड लग सकते हैं
  • डिवाइस इस ऑपरेशन के दौरान डिस्कनेक्ट और रीसेट होगा
  • सभी उपयोगकर्ता डेटा जिसमें जोड़े गए डिवाइस, सेटिंग्स और संग्रहीत मीडिया शामिल हैं, मिटा दिया जाएगा
  • रीसेट पूरा होने के बाद डिवाइस स्वचालित रूप से पुनः आरंभ होगा
