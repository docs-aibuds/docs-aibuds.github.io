ऑपरेशन और फ़ंक्शन

DeviceOperation device-reported input और DeviceFunction उस input को assign behavior बताता है।

नीचे के symbols logical controls समझाते हैं। चित्र device shape, control placement या किसी product का gesture layout निर्धारित नहीं करते।
