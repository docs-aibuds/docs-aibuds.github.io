आम समस्याएँ

आम समस्याओं का कारण पहचानने और उन्हें हल करने के लिए नीचे दिए सुझाव देखें।

1. कनेक्ट होते ही Feature Call विफल होता है​

SDK द्वारा services discover करने, protocol channel खोलने और device state load करने से पहले BLE connection बन जाता है। इस बीच किए गए feature calls विफल हो सकते हैं क्योंकि डिवाइस अभी ready नहीं है।

Connect करने से पहले device delegate set करें। Feature call से पहले deviceDidReady(...) की प्रतीक्षा करें या पुष्टि करें कि isConnectedAndReady true है। Reconnect होने पर नए ready event की दोबारा प्रतीक्षा करें।

2. Feature Code में है, लेकिन कुछ डिवाइस पर काम नहीं करता​

SDK अलग-अलग device models के लिए साझा API surface देता है, लेकिन वास्तविक support device model, firmware, capability flags और supported-value collections पर निर्भर हो सकता है।

UI में feature enable करने से पहले उसकी support information जाँचें। डिवाइस deviceNotSupport लौटाए तो उसी request को दोहराने के बजाय उस डिवाइस के लिए feature unavailable मानें।

3. Hotspot जुड़ता है, लेकिन प्रक्रिया पूरी नहीं होती​

Media File Import, RTSP और Camera OTA Bluetooth control से device-hosted Wi-Fi hotspot पर switch होते हैं। Hotspot से जुड़ना केवल बीच का चरण है।

अंतिम feature callback तक device, workflow owner और callbacks को alive रखें और उसी समय दूसरा hotspot workflow शुरू न करें। Hotspot connection टूट जाए तो पुराना URL reuse करने के बजाय पूरा workflow दोबारा शुरू करें। आवश्यक setup Installation में दिया है।

4. डिवाइस कनेक्ट होने के बाद भी AI Features उपलब्ध नहीं​

Bluetooth connection और AI service authentication अलग states हैं।

Bundled provider के लिए AIBudsAISDK initialize करें, चुना provider configure करें और device authorization state की प्रतीक्षा करें। App की अपनी AI service के लिए host app में authentication पूरा करके परिणाम reportSelfAiServiceAuthResult से बताएँ; इसके बिना डिवाइस नहीं जान सकता कि service authorized है। Self-AI प्रमाणीकरण परिणाम बताएँ देखें।

और सहायता चाहिए तो​

Issue Report Template का उपयोग करें, ताकि report में जाँच के लिए आवश्यक environment, device state, reproduction steps, error और diagnostics शामिल हों।
