लॉगिंग का परिचय

AIBudsLogSDK AIBuds SDK modules और apps के लिए process-wide logging entry point देता है। इसका active LogService messages record करता है, retained logs export करता है और expired entries हटाता है।

उपलब्ध सुविधाएँ​

📄️आउटपुट के तरीके

Active AIBuds logging level और output destination configure करें

📄️लॉग एक्सपोर्ट करें

सहेजे गए AIBuds logs को एक file या सीमित आकार वाली files में export करें

📄️पुराने लॉग हटाएँ

अधिकतम उम्र या cutoff date के आधार पर सहेजे गए logs हटाएँ

लॉगिंग मॉडल​

LogConfiguration इन settings को नियंत्रित करता है:

SettingDefaultउपयोग
level.infoDefault logger द्वारा record की जाने वाली न्यूनतम severity।
destination.xlfacilityActive output destination।
logsDirectory.aibuds/logsDocuments के सापेक्ष log file directory।
maxFileSize10,000,000 bytesएक log file का अधिकतम आकार।
logFileMaxAge3 दिनLog cleanup के लिए retention अवधि।

LogDestination .console, .oslogger, .file और .xlfacility को support करता है। एक समय में केवल एक destination active रहता है।

इंटीग्रेशन प्रक्रिया​

  1. App startup की शुरुआत में level, destination, storage और retention settings configure करें।
  2. .xlfacility उपयोग करने पर logs लिखे जाने से पहले AIBudsXLFacility plugin install करें।
  3. AIBudsLogSDK.logService से messages record करें या AIBuds modules को यही service उपयोग करने दें।
  4. Active LogService से logs export या purge करें।

महत्वपूर्ण व्यवहार​

  • Console और OS Logger destinations export support नहीं करते।
  • File और XLFacility destinations export तथा retention cleanup support करते हैं।
  • Custom service install न होने पर AIBudsLogSDK.logService built-in DefaultLogger लौटाता है।
  • Plugin configure किए बिना .xlfacility चुनने पर console में error message मिलता है और XLFacility के जरिए logs persist या export नहीं हो सकते।
