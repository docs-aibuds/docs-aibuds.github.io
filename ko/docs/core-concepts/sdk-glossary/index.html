SDK 용어집

AIBuds SDK 문서에서 사용하는 용어를 간단히 정리합니다. 각 기능의 사용법은 기능 가이드에서, SDK 구성 요소의 관계는 아키텍처에서 확인하세요.

Bluetooth 및 연결​

BLEBluetooth Low Energy

기기 검색, SDK 제어 연결 및 명령 교환에 사용하는 무선 경로입니다. 지원 기기 프로토콜은 ABMate 모듈에서 구현합니다.

RSSIReceived Signal Strength Indicator

BLE 광고의 수신 강도를 나타내는 부호 있는 dBm 값입니다. 근접 여부를 판단하는 참고값이며 거리나 연결 품질을 보장하지 않습니다.

Advertisement Data

peripheral의 BLE broadcast에 포함된 metadata입니다. 발견된 기기 handle에서 peripheral 및 RSSI와 함께 확인할 수 있습니다.

Core Bluetooth ObjectsCBCentralManager / CBPeripheral

Apple의 central manager는 검색과 연결을 관리하고, peripheral은 원격 BLE 기기 하나를 나타냅니다. SDK는 이를 자체 기기 추상화로 감쌉니다.

Classic Bluetooth

주로 오디오 profile에 사용하는 별도 Bluetooth 경로입니다. 연결 상태는 BLE 제어 연결과 독립적입니다.

SCOSynchronous Connection-Oriented

지원 기기에서 통화 또는 양방향 음성에 사용하는 Classic Bluetooth 음성 링크입니다.

Beacon Data

기기 연결 없이 broadcast되는 선택적 manufacturer data입니다. 발견된 기기가 beacon payload를 제공할 때만 사용하세요.

기기 개념​

Discovered DeviceFoundDeviceConvertible

검색 결과를 나타내는 FoundDeviceConvertible입니다. 저장하거나 연결하기 전에 SDK를 통해 변환하세요.

Storable DeviceDeviceConvertible

식별, 연결 상태, 저장, 명령, delegate 및 기능 확인에 사용하는 영구 DeviceConvertible handle입니다.

StoredDevicesMgr

앱에 저장된 기기 목록을 프로세스 전체에서 관리합니다. 저장된 기기는 지원되는 자동 재연결 대상이 될 수 있습니다.

Device Ready

연결 후 SDK handshake까지 완료된 lifecycle 상태입니다. 기능 명령은 deviceDidReady를 기다리거나 isConnectedAndReady를 확인한 뒤 보내세요.

Capability Protocol

기기가 해당 기능을 지원할 때만 구현하는 작은 선택적 *API 프로토콜입니다. 모든 모델이 같은 기능을 지원한다고 가정하지 말고 필요한 프로토콜로 cast하세요.

Device State

기기가 보고하는 동작 상태입니다. BLE 링크만 나타내는 Core Bluetooth의 peripheral state와는 다릅니다.

Work Mode / Work State

Work mode는 설정된 동작 모드이고 work state는 현재 보고된 활동입니다. 둘 다 delegate event에 따라 바뀔 수 있는 기기 snapshot으로 취급하세요.

Wear Detection

착용 감지 지원 여부, 활성화 상태 및 현재 착용 상태를 보고하는 기기 기능입니다.

TWSTrue Wireless Stereo

좌우가 pair된 무선 기기를 나타냅니다. SDK는 TWS 기기 여부와 상대 기기의 현재 연결 여부를 각각 제공합니다.

Auto Reconnect

앱 실행 또는 Bluetooth 재시작 후 저장된 기기를 다시 찾았을 때 재연결할지를 기기별로 제어합니다. 초기값은 SDK configuration에서 가져옵니다.

오디오 및 음성​

VADVoice Activity Detection

음성과 무음 또는 배경 소음을 구분하는 신호 처리입니다. AI 오디오 연동에서 입력 음성을 나누거나 통과 여부를 결정하는 데 사용할 수 있습니다.

Standard Recording

기기 오디오 녹음 기능으로 시작하고 종료하는 기기 측 녹음입니다. 명령 결과가 로컬 오디오 파일을 직접 반환하지는 않습니다.

AI Audio Recording

기기와 AI 서비스를 연동하는 흐름입니다. 기기가 오디오를 제공하고 선택한 서비스가 session event, transcript 업데이트 및 최종 report를 생성합니다.

Recording Scene

AI 오디오 캡처를 시작할 때 전달하는 기기 녹음 context입니다. 공개 값은 현장 녹음과 통화 녹음을 구분합니다.

PCMPulse-Code Modulation

압축하지 않은 디지털 오디오 sample입니다. 처리하기 쉽지만 압축 오디오보다 대역폭과 저장 공간을 더 사용합니다.

Opus

지원되는 음성 및 streaming 경로에서 사용하는 저지연 압축 오디오 codec입니다.

On-Device Voice Assistant

지원 wearable firmware에서 OnDeviceVoiceAssistantAPI로 제공되는 호출어 및 명령 처리 기능입니다. 인증에는 등록된 bridge plugin과 연동 환경이 필요할 수 있습니다.

AI 및 음성 처리​

ASRAutomatic Speech Recognition

음성을 텍스트로 변환합니다. SDK는 session 기반 streaming recognition과 지원 입력용 service API를 모두 제공합니다.

Streaming ASR

최종 결과를 기다리지 않고 오디오 수신 중 transcript를 계속 업데이트하는 인식 방식입니다.

TTSText to Speech

텍스트를 오디오 파일로 변환합니다. TTSResultModel에서 상대 audioFile, audioFormat 및 해석된 audioFilePath를 제공합니다.

AI Summary

원문이나 transcript에서 요약 결과를 생성합니다. 지원 서비스는 결과를 점진적으로 전달할 수 있습니다.

Text Translation

입력한 텍스트를 설정된 언어 사이에서 번역합니다. 연속 음성 session 흐름과는 별도 기능입니다.

Simultaneous Interpretation

입력 오디오, streaming recognition, 번역 및 지원 대상 언어 음성 출력을 결합한 live session입니다.

AI Chat

AI 서비스를 사용하는 대화 session입니다. transcript, chat, intent, 음성, lifecycle, error 및 최종 report event를 전달할 수 있습니다.

AI Intent

대화에서 추출한 구조화 action data입니다. 자유 형식 텍스트와 별개이며 선택한 서비스가 전달했을 때만 의미가 있습니다.

AI Service ProviderAIServiceVendor / AIBudsAIServiceVendor

AI 서비스 호출에 사용하는 등록된 서비스입니다. 공개 enum의 API 이름에는 Vendor가 유지되지만 개발자 문서에서는 service provider라고 부릅니다. 모듈 설치, 등록, 초기화 및 선택은 각각 별도 단계입니다.

StarBurst AI.starBurst / AIBudsAIServiceVendorStarBurst

ByteDance가 제공하는 AI 서비스입니다. AI 서비스 호출에 선택하기 전에 AIBudsStarBurst 모듈의 StarBurstSDK로 등록합니다.

MltCloud AI.mltcloud / AIBudsAIServiceVendorMltcloud

Meilc가 제공하는 AI 서비스입니다. AI 서비스 호출에 선택하기 전에 AIBudsMagicHelper 모듈의 MagicHelperSDK로 등록합니다.

Authorized Services

지원 서비스 중 인증 handshake를 완료한 항목을 기기가 보고하는 bitmask입니다. 설치된 모든 AI 모듈의 목록은 아닙니다.

AI Dashboard

개발 또는 문제 해결 과정에서 AI session, event, report 및 error를 확인하는 선택적 로컬 진단 화면입니다.

사운드 조정​

EQEqualizer

주파수 band별 gain을 적용하는 기기 설정입니다. custom EQ 제약은 아직 완전한 공개 계약이 아니므로 기기가 보고한 설정을 우선 사용하세요.

Preset EQ

factory tuning profile처럼 기기가 제공하는 equalizer 설정입니다. 사용 가능한 preset은 기기와 firmware에 따라 다릅니다.

ANCActive Noise Cancellation

주변 소리를 줄이는 기기 처리 기능입니다. 공개 mode에서는 normal과 transparency 동작도 구분합니다.

Transparency Mode

주변 소리를 억제하지 않고 wearable로 전달하는 ANC mode입니다.

ANC Fade

ANC 동작을 점진적으로 전환하는 설정입니다. 실제 음향 효과는 기기 구현에 따라 달라집니다.

Volume Domains

system prompt, media, call 및 읽기 가능한 local playback state의 독립된 음량 값입니다. 변경 UI를 제공하기 전에 기기 기능을 확인하세요.

VolumeSetCapability

현재 기기가 지원하는 음량 설정 작업을 나타내는 bitmask입니다.

이미지, Streaming 및 Storage​

Remote Shutter

host app의 camera 실행, 촬영 또는 종료를 기기가 요청하는 기능입니다. camera 작업은 앱이 수행하고 결과 상태를 기기에 보고합니다.

Capture Mode

CaptureMode의 .camera는 고해상도 사진을 기기에 저장하고 .ai는 320×240 JPEG를 앱으로 전송합니다.

RTSPReal-Time Streaming Protocol

hotspot 및 streaming 흐름이 성공한 뒤 지원 기기의 live camera stream을 재생하는 session URL입니다.

JPEG Live Streaming

압축된 완전한 JPEG 이미지를 callback으로 전달하는 stream입니다. 각 callback은 decode 전 raw video frame이 아닌 이미지 하나를 제공합니다.

RTMPReal-Time Messaging Protocol

live stream을 호환 endpoint로 중계하는 선택적 게시 경로입니다. lifecycle은 기기 session 및 local player와 별도로 관리합니다.

Media File Import

DeviceMediaFileImportAPI가 제공하는 기기-앱 hotspot 흐름입니다. metadata 조회, 선택 파일 download 및 선택적 로컬 video stabilization을 수행할 수 있습니다.

MediaCountInfoModel

새로 고침 요청 성공 후 기기가 보고한 지원 media category별 현재 개수입니다.

StorageInfoModel

기기가 보고한 현재 사용 공간과 여유 공간입니다. 공개 model에서는 megabyte 단위로 표시합니다.

OTA 업데이트​

OTAOver-the-Air Update

host app에서 제공한 호환 로컬 firmware package로 기기의 main firmware를 업데이트합니다.

Camera OTA

지원 camera module용 별도 firmware 업데이트 흐름입니다. hotspot 연결, 로컬 HTTP 전달, 전송, flashing 및 완료 확인을 포함합니다.

OTA Battery Limit

main firmware 업데이트 시작에 필요한 최소 기기 battery percentage입니다. 보고값이 0이면 battery threshold가 없습니다.

SDK 아키텍처​

SDKDelegate / DeviceDelegate

SDKDelegate는 SDK 전체 검색 및 기기 event를, DeviceDelegate는 개별 기기 event를 받습니다.

All-in-One

지원 SDK 전체를 함께 설치하고 초기화하는 구성입니다. modular integration을 사용하면 host app에서 dependency와 plugin을 더 세밀하게 제어할 수 있습니다.

Bridge Plugin

서비스별 인증 또는 기능을 공개 plugin boundary를 통해 core SDK에 연결하는 선택적 adapter입니다.

ConnectParams

user identity, pairing data, Classic Bluetooth 설정 및 선택적 AI 인증 parameter처럼 연결마다 지정하는 값입니다.

LogService

프로세스 전체에서 활성화된 LogService backend입니다. 설정한 하나의 대상이 출력을 처리하며 지원되는 영구 대상은 export와 cleanup도 제공합니다.

SDKConfiguration

log level, scan timeout, 자동 재연결 및 알려진 기기 검색 filtering 등 확인된 SDK 동작의 초기화 기본값입니다.
