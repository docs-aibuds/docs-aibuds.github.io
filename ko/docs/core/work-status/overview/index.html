작업 상태 개요

이 문서에서는 기기가 현재 수행 중인 작업을 실시간으로 확인하는 작업 상태 API를 설명합니다.

공식 “AIBuds 작업 상태 및 모드 관리” 스킬을 사용해 앱에 맞게 구현하세요.

https://docs-aibuds.github.io/skills/manage-aibuds-work-state-and-mode을 읽고 지침을 따르세요. 이 스킬로 “AIBuds 작업 상태 및 모드 관리”을 이 iOS 프로젝트에 구현하고 검증하세요.
공식 스킬 보기↗

시작하기​

작업 상태를 확인하려면 다음 순서로 진행하세요.

  1. 기기 연결 - AIBuds 기기와 연결합니다.
  2. 프로토콜 확인 - 기기가 DeviceWorkStateAPI 프로토콜을 준수하는지 확인합니다.
  3. 상태 확인 - 현재 workState 속성을 읽습니다.
  4. 변경 감지 - 기기 delegate에 device(_:didWorkStateChanged:)을 구현합니다.

핵심 개념​

작업 상태​

전체 WorkState 정의는 작업 상태 목록을 참고하세요. 값은 다음과 같이 분류됩니다.

  • 연결 및 대기: 연결 대기, 연결 후 대기 또는 연결 해제 후 대기 상태
  • 재생 및 통신: 로컬 음악 재생, 전화 통화 또는 AI 대화 상태
  • 촬영 및 전송: 사진 촬영, 동영상·오디오 녹음, 파일 전송 또는 스트리밍 상태
  • 유지 관리: 공장 초기화, OTA 업데이트, 종료 또는 기기 테스트 상태

프로토콜 참고​

작업 상태 기능은 DeviceWorkStateAPI 프로토콜을 통해 사용합니다.

  • Swift
  • Objective-C

권장 사항​

  1. 프로토콜 확인: 기기가 DeviceWorkStateAPI 프로토콜을 지원하는지 항상 확인하세요.
  2. 상태 관찰: 상태가 변경되면 기기 delegate 콜백에서 UI를 업데이트하세요.
  3. 상태 전환 처리: 기기 상태가 바뀔 때 적절히 대응하세요.
  4. 충돌 방지: 현재 상태와 충돌하는 작업을 시작하지 마세요.

참고​

  • 작업 상태는 기기의 현재 활동을 실시간으로 나타냅니다.
  • 작업 상태 변경은 선택적 기기 delegate 콜백으로 전달될 수 있습니다.
  • 일부 상태에서는 특정 작업을 수행할 수 없습니다.
