기기 상세 정보 조회

AIBuds 기기에서 현재 사용할 수 있는 정보를 조회합니다. 기기 상세 정보는 기기 객체의 속성으로 제공되며, 단일 getDeviceDetails 요청이나 DeviceDetails 결과 모델은 없습니다.

식별 정보, 펌웨어, 연결 및 광고 정보에는 DeviceConvertible을 사용합니다. 기기가 DeviceInfoAPI도 준수하면 배터리 상태, 보고된 기능, 하드웨어 구성, 언어 설정, 통화 상태, 저장 공간 정보 및 미디어 수를 읽을 수 있습니다.

사전 요구 사항​

기기 상세 정보를 읽기 전에 다음 사항을 확인하세요.

  • 스캔, 저장된 기기 목록 또는 연결 흐름에서 DeviceConvertible 인스턴스를 가져옵니다.
  • 기기가 보고한 최신 값이 필요하면 연결이 완료되고 사용 준비가 될 때까지 기다립니다.
  • SDK나 기기가 값을 제공하기 전까지 선택적 속성은 사용할 수 없는 것으로 처리합니다.

:::info 현재 스냅샷 이 속성을 읽어도 Bluetooth 명령은 전송되지 않습니다. 값은 SDK의 현재 스냅샷이며 검색 데이터, 저장된 기기 데이터 또는 활성 연결 중 수신한 정보에서 가져올 수 있습니다. :::

API Reference​

Framework​

AIBuds.xcframework

Import​

SDK를 사용할 파일에서 기본 프레임워크를 가져옵니다.

  • Swift
  • Objective-C

프로토콜​

기기 상세 정보는 두 프로토콜을 통해 제공됩니다. DeviceConvertible은 기본 기기 스냅샷을 제공하며, 연결된 기기가 DeviceInfoAPI를 지원하면 추가 기기 정보 속성을 사용할 수 있습니다.

  • Swift
  • Objective-C

속성​

기본 기기 속성​

다음 속성은 DeviceConvertible을 통해 사용할 수 있습니다.

분류속성참고
식별 정보name, uuid, bluetoothName, macAddress, product, shapeSDK가 현재 알고 있는 기기 이름, 식별자, 제품 카테고리 및 기기가 명시적으로 알린 형태입니다.
하드웨어deviceModel, deviceSerialNum, formatedProjNumber지원되는 기기에서 보고하는 선택적 값입니다.
펌웨어firmwareVersion, formatedFirmwareVersion, coProcessorFirmwareVersionformatedFirmwareVersion은 데모에서 표시용으로 사용하는 기본 펌웨어 문자열입니다.
연결connectionState, deviceState, isConnectedAndReady, isBusy, lastConnectTime실시간 기기 상태를 사용하기 전에 isConnectedAndReady를 확인하세요.
바인딩bindUserId, userBindTime, isAlreadyUnbind, shouldAutoReconnectWhenAppLaunchSDK가 관리하는 바인딩 및 재연결 상태입니다.
광고advertisementDataString, advertisementRawData, manufacturerData, manufacturerHexDataString, timestampOfAdvertisementData가장 최근에 수신한 광고 데이터에서 파생된 값입니다.
표시thumbnail, screenName, customContent호스트 앱 UI에서 사용할 수 있는 선택적 값입니다.

제품 카테고리와 형태​

product는 DeviceProduct를 사용해 기기 카테고리를 나타냅니다.

값카테고리
.watch, .ring, .glasses시계, 반지 또는 안경
.chargingCase, .earbuds, .speaker, .headphones충전 케이스 또는 오디오 제품
.screenlessBand, .screenBand화면이 없거나 있는 밴드
.eyeMask, .earrings, .electronicBadge아이 마스크, 귀걸이 또는 전자 배지
.unknown제품 카테고리를 확인할 수 없거나 인식하지 못함

shape는 DeviceShape를 사용하며 product와 독립적입니다.

값의미
.round기기가 원형 디스플레이 또는 외형을 명시적으로 알립니다.
.square기기가 사각형 디스플레이 또는 외형을 명시적으로 알립니다.
.unknown레거시 기기나 형태를 지정하지 않은 기기처럼 형태 정보를 확인할 수 없습니다.

제품 카테고리만으로 형태를 추정하지 마세요. 예를 들어 반지나 안경으로 인식되더라도 특정 형태를 의미하지는 않습니다. 형태 정보를 명시적으로 알리지 않는 ABMate 기기는 .unknown을 반환합니다.

기기 정보 속성​

DeviceInfoAPI 준수 여부를 확인한 후 다음 추가 스냅샷 값을 사용할 수 있습니다.

속성타입설명
batteryStatusInfoBatteryStatusModel?기기 배터리 구성 요소의 실시간 정보입니다.
deviceCapabilitiesDeviceCapabilities?기기가 보고한 정규화된 기능 플래그이며, 유효한 기능 정보를 받기 전에는 nil입니다.
hardwareConfigurationDeviceHardwareConfiguration기기가 보고한 물리적 입력 하드웨어 및 기기 내 안내 요구 사항입니다.
languageSettingDeviceLanguage현재 기기 언어입니다.
supportedLanguages[NSNumber]기기가 지원하는 원시 DeviceLanguage 값입니다.
callStatusCallStatus현재 통화 상태입니다.
storageInfoStorageInfoModel?사용 중인 공간과 여유 공간을 MB 단위로 나타냅니다.
mediaCountInfoMediaCountInfoModel?사진, 동영상 및 오디오 파일 수입니다.
isSupportAdjustRecordDurationBool최대 녹음 시간을 구성할 수 있는지 여부입니다.
aiSolutionCapabilitiesAIBudsAISolutionCapabilities기기가 보고한 AI 솔루션 기능입니다.
coprocessorModelCoprocessorModel기기의 보조 프로세서 모델입니다.
imageEnhancementPostProcessingAlgorithmImageEnhancementPostProcessingAlgorithm기기가 현재 보고한 이미지 향상 후처리 알고리즘이며 기본값은 .general입니다.
recommendedMaxVideoRecordingDurationOptions[NSNumber]기기가 권장하는 최대 동영상 녹화 시간 옵션(분)이며 기본값은 [1, 3, 9, 12]입니다.
recommendedMaxAudioRecordingDurationOptions[NSNumber]기기가 권장하는 최대 오디오 녹음 시간 옵션(분)이며 기본값은 [30, 60, 120]입니다.
minimumBatteryLevelForMediaOperationsInt사진, 동영상, 오디오 및 파일 전송에 필요한 최소 배터리 비율이며 기본값은 30입니다. OTA에는 별도 규칙이 적용됩니다.

공통 상태 값​

batteryStatusInfo에는 제품에서 지원하는 다음 구성 요소가 포함될 수 있습니다.

BatteryComponent의미
.glass안경 본체
.leftEarbud / .rightEarbud왼쪽 또는 오른쪽 이어버드
.chargingCase충전 케이스
.mainSpeaker / .sideSpeaker기본 또는 보조 스피커
.headphones오버이어 헤드폰
.mainDevice단일 배터리 웨어러블 기기의 주 배터리
.unknown구성 요소를 사용할 수 없거나 인식할 수 없음

deviceCapabilities 필드로 TWS, 공간 오디오, 멀티포인트, ANC, 기기 내 음성 비서, 베이스 엔진, 라이브 스트리밍, Ximalaya 및 공장 테스트용 처프음을 제공할지 결정하세요. product만으로 기능을 추론하지 마세요. nil은 아직 유효한 기능 정보를 받지 못했다는 뜻이며 모든 기능이 지원되지 않는다는 뜻은 아닙니다.

hardwareConfiguration은 제품을 조작하는 방법을 설명합니다.

속성의미
hasTouchInput터치 입력 표면이 있습니다.
hasPhysicalButtonInput물리 버튼 입력이 있습니다.
requiresOnDeviceVoiceAssistantGuidance호스트 앱에서 기기 내 음성 비서 사용 안내를 제공해야 합니다.

aiSolutionCapabilities는 기기가 지원하는 AI 솔루션을 나타내는 옵션 집합입니다. Swift에서는 AISolutionCapabilities를, Objective-C에서는 AIBudsAISolutionCapabilities를 사용합니다.

SwiftObjective-CAI 솔루션 및 제공업체
.starBurstAIBudsAISolutionCapabilitiesStarBurstStarBurst, ByteDance 제공
.mltcloudAIBudsAISolutionCapabilitiesMltCloudMltCloud AI 솔루션
.watchfunAIBudsAISolutionCapabilitiesWatchFunWatchFun, WoQi(沃奇) 제공
.xksmartAIBudsAISolutionCapabilitiesXKSmartXKSmart, YanJie(岩界) 제공
.topstepAIBudsAISolutionCapabilitiesTopStepTopStep AI 솔루션(拓步自研)

Swift에서는 containsAny(_:) 또는 containsAll(_:)로 옵션 집합을 확인하고, Objective-C에서는 비트 연산으로 확인합니다. 비트 위치가 연속적이지 않으므로 원시 값을 직접 작성하지 마세요.

callStatus는 CallStatus를 사용합니다.

값의미
.notInCall진행 중인 통화가 없습니다.
.ringing수신 전화가 울리고 있습니다.
.inCall통화가 진행 중입니다.
.threeWayRinging지원되는 경우 3자 통화가 울리고 있습니다.
.aiChat기기가 현재 통화 채널 활동을 AI 대화로 보고합니다.
.unknown통화 상태를 사용할 수 없거나 인식할 수 없습니다.

사용 예제​

기기 상세 정보 읽기​

다음 예제는 SDK 데모의 DeviceInfoDetailsController와 같은 방식을 사용합니다. 먼저 기본 기기 속성을 읽은 다음 조건에 따라 DeviceInfoAPI 속성을 추가합니다.

  • Swift
  • Objective-C

반환된 행은 앱의 뷰 모델과 현지화 체계에 맞춰 표시하세요. 데모는 테이블 뷰를 사용하며 열거형 값을 현지화된 표시 문자열로 변환합니다.

저장 공간 또는 미디어 정보 새로 고침​

storageInfo와 mediaCountInfo는 스냅샷 속성입니다. 화면에 최신 값이 필요하면 먼저 업데이트를 요청하고 작업이 성공한 후 해당 속성을 읽으세요.

  • Swift
  • Objective-C

Swift에서는 requestQueryMediaCountInfo(_:), Objective-C에서는 requestQueryMediaCountInfoWithCompletion:을 사용해 mediaCountInfo를 새로 고치세요.

오류 처리​

속성 접근 자체는 비동기 오류를 반환하지 않습니다. 명시적인 새로 고침 작업은 완료 핸들러를 통해 실패를 보고합니다. 사용할 수 없는 정보는 다음과 같이 처리하세요.

  1. 실시간 값이 필요하면 device.isConnectedAndReady를 확인합니다.
  2. DeviceInfoAPI 속성을 읽기 전에 프로토콜 준수 여부를 확인합니다.
  3. 모든 기기 모델이 모든 값을 보고한다고 가정하지 말고 선택적 속성을 처리하세요. nil인 deviceCapabilities는 미지원이 아니라 알 수 없음으로 처리하세요.
  4. 광고 필드는 가장 최근에 수신한 광고 스냅샷으로 처리합니다.
  5. 저장 공간 또는 미디어 수 조회와 같은 명시적 새로 고침 작업에서는 success와 error를 처리합니다.

권장 사항​

  1. 프로토콜 준수 확인: 확장 속성을 읽기 전에 DeviceInfoAPI 지원 여부를 확인하세요.

  2. 보고된 값으로 기능 제어: 제품명이나 하드코딩된 제한 대신 deviceCapabilities의 정규화된 플래그, 권장 녹화·녹음 시간 배열 및 minimumBatteryLevelForMediaOperations를 우선 사용하세요.

  3. 값을 스냅샷으로 처리: 모든 속성이 동시에 갱신되었다고 가정하지 마세요.

  4. 선택적 값 처리: 임의의 대체 기기 데이터를 만들지 말고 사용할 수 없음 상태를 표시하세요.

  5. 필요할 때만 갱신: 화면에 현재 값이 필요할 때 저장 공간 및 미디어 수 쿼리 메서드를 사용하세요.

  6. 표시 값 현지화: 제품, 언어, 통화 상태 및 기타 열거형을 사용자용 현지화 텍스트로 변환하세요.

참고​

  • 기기 기능과 사용 가능한 필드는 제품 및 펌웨어에 따라 다릅니다. DeviceProduct는 제품 카테고리, DeviceShape는 명시적으로 알려진 형태, BatteryComponent는 개별 배터리 항목을 나타냅니다.
  • supportedLanguages에는 NSNumber 값이 포함되며, 각 값은 DeviceLanguage.rawValue에 대응합니다.
  • StorageInfoModel은 usedSpaceInMB와 freeSpaceInMB를 제공합니다.
  • MediaCountInfoModel은 photoCount, videoCount, audioCount를 제공합니다.
  • UI에서 개별 값이 필요하면 description을 파싱하지 말고 모델 속성을 사용하세요.
