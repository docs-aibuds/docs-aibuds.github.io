조작 및 기능

DeviceOperation은 기기가 보고하는 입력을 나타냅니다. DeviceFunction은 해당 입력에 할당되는 동작을 나타냅니다.

아래 기호는 논리적인 조작을 설명합니다. 그림은 의도적으로 단순화되어 있으며 기기 형태, 버튼 위치 또는 제품별 제스처 구성을 규정하지 않습니다.

기기 매핑 사용​

연결된 기기에서는 physicalOperationsMapping을 기준으로 사용하세요. 해당 매핑이 보고한 조작만 표시하고, 기능 할당은 기기가 성공으로 응답한 뒤에만 지원되는 것으로 처리하세요.
