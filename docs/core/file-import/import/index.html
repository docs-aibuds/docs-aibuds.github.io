Prerequisites​

  • The device is connected and conforms to DeviceMediaFileImportAPI.
  • The app can join the device Wi-Fi hotspot and has the required local-network permissions.
  • Keep the returned media models; imports accept models, not arbitrary file IDs or destination paths.

Protocol Symbols​

SymbolPurpose
isVideoStabilizationAvailableWhether SDK-managed stabilization is currently available.
fetchMediaFilesInfoPrepare transfer mode and return device media information.
importMediaFilesDownload selected files and optionally post-process video.
cancelMediaFileImportCancel transfer or active post-processing.
deleteMediaFileDelete one device file by file name.
deleteAllMediaFilesDelete all device media files.

Declarations​

The declarations preserve the SDK's multi-stage callback contract.

  • Swift
  • Objective-C

Return Value​

These members do not return operation results directly. Results arrive through their completion and progress handlers. fetchMediaFilesInfo supplies the MediaFileInfoModel values accepted by importMediaFiles; cancel and delete operations also supply an optional device status code.

Error Handling​

Treat hotspot configuration, transfer-mode entry, hotspot connection, file download, and stabilization as separate phases in the UI. A stabilization failure does not necessarily mean the original download failed; inspect each imported result model and use its original local URL when the playable stabilized URL is unavailable.

Do not infer undocumented status-code meanings. For cancel and delete operations, use success and error as the primary result until the SDK publishes the status-code contract.

Best Practices​

  1. Check protocol conformance before starting the pipeline.
  2. Pass the MediaFileInfoModel objects returned by fetchMediaFilesInfo to importMediaFiles; do not replace them with custom IDs.
  3. Present hotspot configuration, transfer-mode entry, hotspot connection, download, and stabilization as distinct UI phases.
  4. Dispatch UI updates to the main queue because progress callbacks may arrive on another queue.
  5. Copy imported files from temporary SDK locations into app-managed persistent storage when they must survive future sessions.
  6. Prevent duplicate import requests while a transfer is active and expose cancellation when appropriate.

Notes​

  • Import remains available when isVideoStabilizationAvailable is false; only SDK-managed stabilization is unavailable.
  • A stabilization failure can still leave a usable original local file. Inspect each ImportedMediaFileModel.
  • deleteMediaFile expects the device file name, not an app-local file URL.
