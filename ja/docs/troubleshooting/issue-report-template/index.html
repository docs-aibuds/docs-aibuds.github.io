問題報告テンプレート

該当する項目を入力し、生成された Markdown テンプレートをサポート窓口に貼り付けて、問題が発生した時間帯のログを添付してください。ログの取得方法はログのエクスポートを参照してください。

AIBuds SDK iOS

問題報告テンプレート

技術サポートへ問い合わせる前に、該当する項目を記入してください。

01

発生日時

ログと照合できるよう、正確な日時とタイムゾーンを記入してください。

YYYY-MM-DD HH:mm:ss UTC+09:00
02

問題の概要

補足情報の前に、確認できる現象を簡潔に説明してください。

1 文の概要と必要最小限の補足
03

添付資料

同じ再現操作に対応する画面とログを添付してください。

IMGスクリーンショットまたは画面収録該当する画面状態や callback の流れを示してください。
LOGエクスポートした SDK ログ発生日時と再現操作全体を含めてください。
04

再現手順

可能な場合は、アプリとデバイスを初期状態にして再現してください。

  1. アプリとデバイスの初期状態
  2. 操作と API 呼び出し
  3. 期待と異なる結果になった箇所
05

期待する結果と実際の結果

期待する結果と実際の結果を分けて記入してください。

期待する結果
実際の結果と再現頻度
