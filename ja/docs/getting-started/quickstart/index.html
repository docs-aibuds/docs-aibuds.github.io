クイックスタート

このガイドでは、AIBuds SDK iOS の基本設定から、よく使う操作までを順に説明します。

ステップ 1：SDK をインポートする​

SDK を使用するファイルで、必要なモジュールをインポートします：

  • Swift
  • Objective-C

ステップ 2：SDK を初期化する​

アプリの起動時に AIBuds SDK を初期化します。通常は AppDelegate または SceneDelegate で行います：

  • Swift
  • Objective-C

ステップ 3：デバイスを検索する​

接続可能な AIBuds デバイスを検索します：

  • Swift
  • Objective-C

ステップ 4：デバイスを追加する​

検索で見つかったデバイスを「マイデバイス」に追加すると、次回のアプリ起動後も利用できます。検索結果の FoundDeviceConvertible を makeStorableDeviceFromDiscovered(_:) で保存可能な形式に変換し、StoredDevicesMgr に保存します：

  • Swift
  • Objective-C

ステップ 5：デバイスに接続する​

保存済みデバイスに ConnectParams を指定して接続します。AI 認証パラメータを渡すと、接続時に SDK が利用する AI サービスの認証も行います：

  • Swift
  • Objective-C

ステップ 6：コマンドを送信する​

接続後は、デバイスにコマンドを送信できます：

  • Swift
  • Objective-C

ステップ 7：デバイスデリゲートを処理する​

DeviceDelegate に準拠すると、接続ライフサイクルのイベントを受け取れます。すべてのメソッドは @objc optional なので、必要なコールバックだけを実装してください：

  • Swift
  • Objective-C

ステップ 8：デバイスを切断する​

デバイスの利用を終えたら、接続を解除します：

  • Swift
  • Objective-C
