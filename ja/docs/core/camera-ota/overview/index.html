カメラ OTA の概要

DeviceCameraOtaAPI を使用して、ローカルファイルからカメラファームウェアを更新します。

カメラ OTA は複数段階の Wi-Fi 処理です。ホットスポットの設定、カメラ OTA モードへの移行、デバイスのホットスポットへの接続、ローカル HTTP サーバーの起動、ファームウェア URL の送信、ファイル転送、書き込み待機、書き込み、完了の順に進みます。各段階に専用のコールバックがあります。進捗値が通知されるのは、公開されている .transferring と .flashing の段階だけです。

この API は、リモートサービスでの更新確認やカメラファームウェアのダウンロードを行いません。開始前にパッケージを選択し、検証してください。
