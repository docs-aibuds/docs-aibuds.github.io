操作と機能

DeviceOperation は、デバイスから通知された入力操作を表します。DeviceFunction は、その入力操作に割り当てる動作を表します。

以下の記号は論理的な操作部を表しています。図は意図的に抽象化されており、デバイスの形状、操作部の配置、製品固有のジェスチャー構成を指定するものではありません。

デバイスが報告するマッピングに従ってください。 エヌメレーションに機能がある場合、デバイスが必ずしも対応する機能割り当てを受け付けるわけではありません。

デバイスの割り当てを使用する​

接続中のデバイスについては、physicalOperationsMapping を正しい情報源として扱います。この割り当てに含まれる操作だけを表示し、変更後の割り当てはデバイスが受け付けた場合にのみ対応済みとして扱ってください。
