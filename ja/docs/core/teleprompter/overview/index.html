テレプロンプターの概要

TeleprompterAPI を使用して、デバイスのオーバーレイプロンプト用スロットを操作します。

利用できる機能​

  • スロットの総数と、現在のゼロ始まりのスロット番号を取得する。
  • 現在のスロットで使用済みの容量と空き容量をバイト単位で取得する。
  • 進行状況を受け取りながら、現在のスロットへテキストを送信する。
  • 現在のスロットを消去する、または有効な別のスロットへ切り替える。
  • 共通のスクロール速度を取得・設定する。範囲は 10（0.1倍）から 1000（10倍）で、100 が1.0倍です。

公開 API は、開始、一時停止、再開、停止、文字揃え、画面上の表示位置を操作する機能を提供していません。以前の仮ドキュメントに記載されていたこれらの操作は、現在の SDK 仕様には含まれません。
