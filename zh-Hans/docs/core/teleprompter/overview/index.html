提词器概览

使用 TeleprompterAPI 管理设备的提词器槽位。

功能概览​

  • 读取槽位总数和当前从零开始的槽位索引。
  • 读取当前槽位已使用和可用的字节容量。
  • 向当前槽位发送文本并接收进度。
  • 清空当前槽位或切换到其他有效槽位。
  • 读取或设置共享滚动速度：10（0.1×）至 1000（10×），其中 100 表示 1.0×。

公开 API 不提供开始、暂停、继续、停止、文本对齐或屏幕位置控制。旧占位文档中的这些行为不属于当前 SDK 契约。
