查看音量能力与级别

读取设备的音量设置能力和当前可用的音量级别。

前置条件​

  • 设备已连接且就绪。
  • 设备支持 DeviceVolumeControlAPI。

API 参考​

框架​

AIBuds.xcframework

导入​

  • Swift
  • Objective-C

协议​

  • Swift
  • Objective-C

属性​

属性类型描述
volumeSetCapabilityVolumeSetCapability音量设置能力。
volumesInfoVolumesInfoModel?当前音量值；不可用时为 nil。

能力值​

值在当前 SDK 中的含义
.none音量设置不可用。
.common可设置系统提示音、媒体和通话中音量。
.advanced当前快照还可报告本地播放音量；目前没有公开的本地播放音量设置方法。

音量信息​

属性类型范围描述
systemPromptVolumeNSNumber?0–100当前系统提示音音量。
mediaVolumeNSNumber?0–100当前媒体播放音量。
callVolumeNSNumber?0–100当前通话中音量。
localPlaybackVolumeNSNumber?0–100当前本地播放音量；通过现有公开 API 只能读取。

使用示例​

  • Swift
  • Objective-C

错误处理​

这些属性没有完成回调。请处理协议不支持、模型为 nil 以及单个通道值为 nil 的情况，不要编造默认值。

最佳实践​

  1. 保留可选值语义：不要将 nil 显示为零。
  2. 根据能力决定 UI：当值为 .none 时隐藏全部写入控件。
  3. 监听更新：需要实时值时，在 didVolumesChanged 代理回调中刷新。

注意事项​

  • SDK 提供同步属性，而不是 getVolumeControlSupport 或基于 Result 的查询。
  • 当前可以读取本地播放音量，但不能单独写入。
