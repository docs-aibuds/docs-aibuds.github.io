离线语音助手概览

离线语音助手在可穿戴设备上执行受支持的唤醒和命令处理。App 可通过 OnDeviceVoiceAssistantAPI 读取设备能力、检查当前模式并请求兼容模式。

能力与模式​

OnDeviceVoiceAssistantCapability 描述设备支持的能力：

能力支持的行为
.none不支持设备端语音命令。
.keywordWakeup仅支持关键词唤醒，例如“Hi Buds”。
.common支持播放、曲目和音量控制等常用命令。

OnDeviceVoiceAssistantMode 描述当前启用的行为：

模式行为
.unknown当前模式不可用，请勿设置此值。
.disabled离线语音助手已禁用。
.basic唤醒和基础语音命令。
.advanced基础行为加通话状态语音控制。

能力决定应提供哪些模式。当前 Demo 对 .keywordWakeup 提供 disabled 和 basic，对 .common 提供 disabled、basic 和 advanced。

前提条件​

  • 设备已连接并就绪。
  • 所需的服务鉴权已完成。
  • 设备提供 OnDeviceVoiceAssistantAPI，且能力不为 .none。
