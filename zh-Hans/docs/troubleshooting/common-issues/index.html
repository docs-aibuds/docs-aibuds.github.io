常见问题

请参考以下建议，排查并解决常见问题。

1. 连接后立即调用功能失败​

BLE 连接会先于服务发现、协议通道建立和设备状态加载完成。在此期间调用功能时，设备尚未就绪，因此调用可能失败。

连接前设置设备 Delegate，随后等待 deviceDidReady(...)，或确认 isConnectedAndReady 为 true 后再调用功能。设备重新连接后，也必须重新等待就绪事件。

2. 代码中存在某项功能，但在部分设备上失败​

SDK 为不同设备型号提供统一 API，但实际支持情况仍取决于设备型号、固件、能力标记和支持值集合。

在 UI 中启用功能前检查其支持信息。如果设备返回 deviceNotSupport，应将该功能视为当前设备不可用，而不是重复发送相同请求。

3. 热点已连接，但功能流程没有结束​

媒体文件导入、RTSP 和 Camera OTA 会从蓝牙控制切换到设备提供的 Wi-Fi 热点。加入热点只是中间阶段。

在最终功能回调到达前，保持设备、流程持有者和回调存活，并且不要同时启动另一个热点流程。如果热点连接中断，请重新启动完整流程，不要复用之前的 URL。所需配置请参阅安装。

4. 设备连接后 AI 功能仍不可用​

蓝牙连接和 AI 服务鉴权是两个独立状态。

使用 SDK 内置 AI 服务商时，请初始化 AIBudsAISDK、选择对应服务商并等待设备完成鉴权。使用自有 AI 服务时，应由宿主 App 完成鉴权，并通过 reportSelfAiServiceAuthResult 上报结果；否则设备无法得知该服务已经通过鉴权。请参阅上报自有 AI 鉴权结果。

仍需帮助时​

请使用问题反馈模板，完整提供排查所需的运行环境、设备状态、复现步骤、错误信息和诊断材料。
